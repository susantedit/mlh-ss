FRONT END

Three.js browser game

HTML, CSS and JavaScript. Real-time 3D arena, first-person controls and five landmarks.

AI MODEL USED

Gemma 4 12B

Gemma 4 12B (cloud-hosted via Ollama / Cloudflare tunnel) generates strategic directives, personality dialogue, and tactical decisions for all NPCs.

LOCAL

Local simulation

Movement, pathfinding, collisions, combat and rules run in the browser, so it stays responsive.

🤖 AI Model Used: Gemma 4 12B — Pure high-level strategic reasoning. Movement & combat physics stay 100% local!

Model: Gemma 4 (12B parameters) · Fallback: Built-in local heuristic engine if cloud tunnel is offline.
